Task Management System
A streamlined task management application designed to organize workflows and track project progress efficiently. This project focuses on a modular component-based architecture to ensure scalability and maintainable code.

Key Features
Intuitive Task Tracking: Create, manage, and monitor task status in real-time.

Modular Architecture: Built with a clean separation of concerns, utilizing dedicated modules for project logic, popup management, and base utilities.

Responsive Styling: Optimized for various screen sizes using Sass for a maintainable and clean CSS structure.

Technical Stack
Core: JavaScript (ES6+)

Styling: Sass/SCSS

Build Process: Compiled build workflow for optimized production deployment.

Project Structure
Plaintext

├── src/            # Source code
│   ├── js/         # Application logic modules
│   └── sass/       # Stylesheets

Getting Started
Clone the repository:
git clone <repository-url>

Install dependencies:
npm install

Run the project:
npm start
